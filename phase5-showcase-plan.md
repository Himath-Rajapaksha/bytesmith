# Phase 5 — Bytesmith Showcase Page

**Goal:** static landing page on Vercel that publicizes the bytesmith skill, and passes its own 36-point audit at ≤15.

**Status:** design APPROVED by user 2026-09-26. Ready to implement.

---

## Constraints (non-negotiable — the page must pass its own audit)

- **Palette:** paper `#fbfaf7`, surface `#f2efe8`, ink `#14181d`, rust `#b4451f`, moss `#4a5d3a`, gold `#8a6d1f`, rule `#d9d3c7`
- **Type:** Charter/Source Serif 4 (display) + Lato (text) + Fira Code (specs)
- **Forbidden:** gradients · Inter · badge-hero · 3-card bento · dual centered CTAs · decorative blobs · uniform soft radius · sparkle emoji
- **Copy must describe the source-code execution model** ("runs inside your project") — NOT a URL-only tool
- **Acceptance:** self-audit of the live URL scores **≤15**

## Layout

- **Hero** asymmetric 7/5. Eyebrow "FORENSIC DESIGN AUDIT FOR THE WEB". H1 "Every AI-built page leaves prints." Right column: **band-ruler artifact** (the 5 score bands as a horizontal measure).
- **How it runs** — repo-first ingest: dev server render + source scan → `file:line`.
- **The 36 points** — parsed live from `checklist.md` (5 groups, weights).
- **The blueprint** — parsed from `countermeasures.md` (5 sections, 36 rows).
- **Sample report** — link to shipped PDF, with page/score facts.
- **Install + one example prompt.**
- Single primary CTA, left-aligned. No second centered CTA.

## Files

| Path | Purpose |
|---|---|
| `site/build.py` | stdlib-only generator. Parses `checklist.md` + `countermeasures.md`; emits `site/dist/index.html` + `styles.css`. Asserts: 36 points, Σw == 37.5, 5 groups A–E, 36 countermeasures, nums contiguous 1–36. |
| `site/test_build.py` | Runs build; asserts output exists, no unreplaced `{{TOKENS}}`, palette hexes present, forbidden patterns absent (gradient/Inter/bento/sparkle), bands listed, `file:line` string present. |
| `site/dist/` | Generated output (gitignored-style; regenerated by build). |
| `vercel.json` | `{"framework": null}` |

## Deploy

Vercel project `bytesmith` → static build of `site/dist`. Verify live URL loads, then run the bytesmith skill against it.

## Steps

1. `site/build.py` — parsers + template + CSS (palette/type as above)
2. `site/test_build.py` — assertions incl. forbidden-pattern checks
3. `python3 site/test_build.py` → all green
4. Deploy to Vercel project `bytesmith`
5. **Self-audit the live URL with the bytesmith skill** → must score ≤15; fix page until it does
6. Mark Phase 5 done in `bytesmith-officialization-todo.md`
